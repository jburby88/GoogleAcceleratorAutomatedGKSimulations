# `itg_surrogate`: Periodic 1D CNN Ensemble Surrogates for Stellarator ITG Turbulence

JAX / Flax / Optax implementation of periodic 1D convolutional neural network (`ResFiLM-MultiPool`) ensemble surrogates for nonlinear gyrokinetic ion-temperature-gradient (ITG) turbulent heat flux $Q / Q_{\mathrm{gB}}$ on the Landreman et al. (2025) GX stellarator dataset (`20250102-01_GX_stellarator_dataset.h5`, [arXiv:2502.11657](https://arxiv.org/pdf/2502.11657), [Zenodo 14867777](https://zenodo.org/records/14867777)).

## Why Only the Stellarator-Grouped Split Is Supported (Zero Equilibrium Leakage)

This package **intentionally excludes uniform random per-flux-tube splits** and supports **only** the stratified stellarator-grouped split (`itg_surrogate.data.splits.make_stellarator_grouped_split`).

### Empirical Leakage Audit of Uniform Random Splits
In `20250102-01_GX_stellarator_dataset.h5` (`100,705` total runs; `98,932` with $Q > 0$), individual rows are *not* independent stellarators. Auditing a standard `80% / 10% / 10%` random split (`N_test = 9,893`) reveals two nested levels of stellarator-identity leakage:

1. **Multiple radial surfaces and field lines per 3D MHD equilibrium (`/equilibrium_files`, `23,577` unique VMEC files):** Each equilibrium contributes ~4 radial flux tubes (and up to ~20 $(\psi, \alpha)$ tubes in QUASR vacuum equilibria). Under a random split, **99.09%** (`9,803 / 9,893`) of held-out test flux tubes share an exact `equilibrium_file` with sibling training flux tubes.
2. **Shared boundary shapes across vacuum and finite-$\beta$ QUASR equilibria (`/QUASR_IDs`, `418` unique positive IDs):** Class 4 (*QUASR configurations with added pressure*, `3,964` equilibria) was generated by adding finite-$\beta$ pressure profiles to the *same* `413` boundary shapes in Class 3 (*QUASR vacuum*, `413` equilibria). Under a random split, **100.00%** (`2,397 / 2,397`) of QUASR test flux tubes share their underlying `QUASR_ID` geometry with training tubes (**99.35%** canonical stellarator overlap overall—only `64` of `9,893` test tubes come from genuinely unseen stellarators). Even grouping by `equilibrium_files` alone leaks QUASR geometries between vacuum and finite-$\beta$.

### Canonical Stellarator Grouping
When deploying a surrogate inside a stellarator optimization loop to evaluate **brand-new candidate configurations**, zero flux tubes from the candidate equilibrium exist in the training set. `make_stellarator_grouped_split` therefore:

- Assigns each row its canonical stellarator family key: `quasr_<QUASR_ID>` whenever `QUASR_ID >= 0` (keeping all vacuum equilibria, finite-$\beta$ equilibria, radial surfaces, and field lines of a QUASR boundary together in one split) and `eq_<equilibrium_file>` whenever `QUASR_ID == -1` (random Fourier and rotating-ellipse equilibria).
- Partitions the **19,618** unique stellarator families (`15,694` train / `1,962` val / `1,962` test -> `79,185` / `9,827` / `9,920` flux tubes) via an `80% / 10% / 10%` split stratified across the 4 disjoint configuration strata (`Random Fourier`, `Rotating-Ellipse Circle`, `Rotating-Ellipse Torsion`, `QUASR Family`).
- Runs `verify_zero_stellarator_leakage()` automatically on every split construction, raising `ValueError` if any `equilibrium_file` or positive `QUASR_ID` overlaps across `train`, `val`, or `test`, and computes feature standardization (`z_mean`, `z_std`, `s_mean`, `s_std`) strictly from `train_idx`.

## Model Registry & Checked-In Leading Baseline (`registry/`)

- **[`registry/leading.py`](src/itg_surrogate/registry/leading.py):** Defines `LEADING_EXPERIMENT` (`resfilm_multipool_80_strong_wd`), the single-family **baseline to beat** on unseen stellarators, alongside `LEADING_OOD_COMBO_EXPERIMENT` and `REFERENCE_OOD_BASELINES`.
- **[`registry/sweeps.py`](src/itg_surrogate/registry/sweeps.py):** Defines reproducible ablation sweeps:
  - `architecture_ladder`: Isolates channel width, smooth activations (`SiLU`/`GELU`), `[mean, max, std]` spatial pooling, Pre-LN zero-init residual connections, and Early FiLM `(a/LT, a/Ln)` conditioning.
  - `ood_regularization`: Isolates clean $L_2$-unbiased regularizers on `ResFiLM-MultiPool-80`—masked kernel weight decay (`wd=1e-2`), depth-scheduled Stochastic Depth (`drop_path_rate=0.14`), exact 192-element Dihedral $D_{96}$ gyrokinetic parity reflection, and Gaussian input Jacobian smoothing.
  - `weight_decay_scan`: Logarithmic scan (`1e-4` to `1e-1`) of masked `AdamW` kernel weight decay.
  - `normalization_diagnostic`: Compares per-sample `LayerNorm` against Figure 7's `BatchNorm` (which suffers running-variance spikes from $>250\sigma\text{--}700\sigma$ tails in $|\nabla y|^2$ and $|\nabla x|^2$).

## Quickstart

```bash
cd itg_surrogate
pip install -e ".[baselines,dev]"

# Inspect the leading baseline-to-beat and registered ablation sweeps:
itg-surrogate list
itg-surrogate show leading

# Train & evaluate the leading 8-seed ResFiLM surrogate (sharded across TPUs/GPUs via jax.sharding):
itg-surrogate train --h5-path /path/to/20250102-01_GX_stellarator_dataset.h5 --experiment leading --with-xgboost

# Run a registered ablation sweep:
itg-surrogate train --h5-path /path/to/20250102-01_GX_stellarator_dataset.h5 --sweep ood_regularization

# Run unit tests:
python3 -m unittest discover -s tests -v
```
